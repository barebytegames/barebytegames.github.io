Barebyte Growth Mailer

Developer: Barebyte · Type: automation, operated by Barebyte only

What it is. Barebyte Growth Mailer is the private tool Barebyte uses to send a game submission — a short email about one of its own games, with official artwork — from Barebyte's own Gmail address to a game website or editor that publicly invites such submissions. It is not a public service: there is no sign-up, no account system and no other user.

What it does

  • Sends one individually written email per website, to the submission address that website publishes for that purpose. It never sends bulk or repeated mail, and never sends to a website that does not invite submissions.
  • Checks each submission before it can be sent: the game's facts, the rights to the attached artwork, the website's own submission rules, and that the same game was not already sent there.
  • Records that the email was sent, so the same submission is never sent twice.

How it uses Gmail

Barebyte Growth Mailer uses the Gmail API, with the permission of Barebyte's own Google account. It uses it to:

  • confirm the account it is connected to is Barebyte's sending address, before any email;
  • send an approved submission email from that address.

It cannot read, search, change or delete any email, contact or other Gmail data: it is granted permission to send only.
