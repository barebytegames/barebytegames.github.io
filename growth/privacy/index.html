Barebyte Growth Mailer Privacy Policy

Application: Barebyte Growth Mailer · Developer: Barebyte · Effective 31 October 2026

The short version. Barebyte Growth Mailer is a private tool that only Barebyte operates, to send submissions about Barebyte's own games from Barebyte's own Gmail address. It may send email and read the connected account's email address — nothing else. It cannot read any mailbox, and it does not sell, share or use any data for anything else.

Who this applies to

Barebyte Growth Mailer is not offered to the public. The only Google account that connects to it is Barebyte's own sending account. It processes no data about anyone else, except the published submission address of the website an email is sent to.

Permissions requested

When the Google account is connected, it is asked to grant exactly three permissions (OAuth scopes):

  • https://www.googleapis.com/auth/gmail.send — to send an approved submission email from the connected account;
  • openid and email — to read the connected account's email address, so the tool can confirm before every email that it is sending from Barebyte's address.

No other Google permission is requested. In particular the tool has no permission to read, search, label, change or delete email, contacts or calendars.

What data is accessed, and why

  • The connected account's email address, and whether Google has verified it. Used only to refuse sending if the wrong account is connected.
  • The receipt Gmail returns for a sent email (its message id and thread id). Kept so the same submission is never sent twice.
  • The authorization tokens Google issues when the account grants access. Used only to make the requests above.

How the data is used

Only to send Barebyte's approved game submissions and to record that they were sent. It is not used for advertising, it is not sold, and it is not used to train any machine-learning or artificial-intelligence model.

Barebyte Growth Mailer's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where the data is kept

  • Authorization tokens are stored as encrypted secrets of Barebyte's private GitHub repository, where the tool runs on GitHub Actions. They are never written to source code, logs or any other place.
  • Send receipts (message id, recipient website, time) are kept in that private repository's submission record.

Barebyte operates no other server for the tool and shares this data with no one.

Retention and revocation

Tokens are kept until access is revoked or replaced; send receipts are kept as long as the submission record is needed to avoid duplicate submissions. Access can be revoked at any time at myaccount.google.com/permissions, after which the tool can no longer send.

Google's handling of data is described in the Google Privacy Policy.

Changes to this policy

If Barebyte Growth Mailer's use of Google data changes — a new permission, new data, a new use — this policy will be updated before that change is used, and the effective date above will change with it.
