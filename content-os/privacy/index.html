Barebyte Content OS Privacy Policy

Application: Barebyte Content OS · Developer: Barebyte · Effective 11 October 2026 · TikTok section added 11 October 2026

The short version. Barebyte Content OS is a private tool that only Barebyte operates, to publish videos of Barebyte's own games to Barebyte's own YouTube channel. It uses the YouTube API Services. It reads only what it needs to confirm the channel and its own uploads, keeps that on Barebyte's computer, and does not sell, share or use it for anything else.

Who this applies to

Barebyte Content OS is not offered to the public. The only Google account that connects to it is the account that manages Barebyte's YouTube channel, and the only data it handles is that channel's. It processes no data about viewers, subscribers or anyone else.

YouTube API Services

Barebyte Content OS uses the YouTube API Services. By connecting a Google account to it, the account holder agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Permissions requested

When the Google account is connected, it is asked to grant exactly two permissions (OAuth scopes):

  • https://www.googleapis.com/auth/youtube.upload — to upload a video that a person at Barebyte has approved;
  • https://www.googleapis.com/auth/youtube.readonly — to read the connected channel's identity and the videos the tool uploaded.

No other Google permission is requested.

What data is accessed, and why

  • Channel identity: the channel's id, name, handle and the list of its uploads. Used to confirm, before every upload, that the connected channel is Barebyte's, and to find a video if an upload was interrupted, so that it is not uploaded twice.
  • The tool's own uploads: each video's id, title, description, tags, privacy setting, upload and processing status, and publication time. Used to confirm that the video arrived on YouTube exactly as it was approved.
  • The authorization token Google issues when the account grants access. Used only to make the requests above.

Barebyte Content OS does not access comments, subscribers, viewing history, playlists other than the channel's own uploads, analytics, revenue, email, contacts or any other Google data.

How the data is used

Only to publish Barebyte's approved videos and to verify that they were published correctly. It is not used for advertising, it is not sold, and it is not used to train any machine-learning or artificial-intelligence model.

Barebyte Content OS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where the data is kept

Barebyte Content OS runs on Barebyte's own computer; Barebyte operates no server for it. The authorization token and the channel's identity are stored there, in files that only the operating system account running the tool can read. The record of each publication — the video's id, the channel's id, the approved title and description, the privacy setting, status and timestamps — is stored there too. None of this is placed in a source-code repository or sent anywhere other than to Google, as part of the requests described above.

Sharing

None. The data described here is not shared with, sold to or disclosed to any third party. The only exchange is between the tool and Google's YouTube API Services, which is how the tool works. The videos themselves are published on YouTube at the privacy setting Barebyte approved.

Retention and deletion

  • The authorization token is kept until it expires or access is revoked. After that it no longer works, and it is overwritten when access is next granted.
  • Publication records are kept while Barebyte needs them to know what it has published, and are deleted when no longer needed.
  • Deleting the tool's local files removes everything it stored. Videos on YouTube are managed in YouTube itself.

Revoking access

Access can be revoked at any time from the Google account's security settings: security.google.com/settings/security/permissions. After revocation the tool can no longer read the channel or upload to it.

TikTok

Barebyte Content OS is being connected to the TikTok API for Business (Accounts API). This section applies once Barebyte's own TikTok account has authorized it; until then the tool holds no TikTok data. Only Barebyte's own account connects; no other TikTok user's data is processed.

  • Permissions: those the account holder grants on TikTok's authorization page for the app's "TikTok Accounts" scope. The tool uses them only to read the account's username and display name, to publish an approved video as a public post, and to read that post's publishing status and its post data (id, caption, link, time, duration).
  • What is kept, and where: on Barebyte's own computer only, in files that only the operating system account running the tool can read — the TikTok authorization tokens and the account's id, username and display name — and, beside them, the record of each post (its approval, publishing id, post id, caption, link and timestamps). None of it is placed in a source-code repository or sent anywhere other than to TikTok.
  • The video: TikTok's API fetches the approved video from a public web address that Barebyte controls; the same video is then public on TikTok.
  • Use and sharing: only to publish Barebyte's approved videos and verify them; never sold, never used for advertising profiles, never used to train any machine-learning or artificial-intelligence model, and not shared with anyone other than TikTok.
  • Retention and revocation: the access token lasts one day and the refresh token one year; they are overwritten when access is next granted. Access can be revoked at any time in the TikTok app, where TikTok lists the apps an account has authorized.

Use of TikTok is subject to the TikTok Terms of Service and the TikTok Privacy Policy.
